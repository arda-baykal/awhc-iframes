# AWHC Mareto Dashboard — IFrame Pages

Static HTML pages embedded in the Mareto Compose dashboard for A Way Home Canada via IFrame blocks.

## Live pages

- [`glossary.html`](https://arda-baykal.github.io/awhc-iframes/glossary.html) — Mareto Glossary (core entities, taxonomy, funding, reporting, system conventions)
- [`lobby-mini.html`](https://arda-baykal.github.io/awhc-iframes/lobby-mini.html) — Lobby Activity widget (KPI tiles + recent reportable events)

## Data files

- `lobby-data.json` — bakes from Corteza events module via `bake_lobby_data.py`; widget fetches it at load time

Hosted via GitHub Pages from the `main` branch root.
